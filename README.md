# 🌦️ Automated Weather Classification System

A Machine Learning project focused on multi-class weather classification using localized meteorological sensor data.

## 📌 Project Overview
This project predicts overarching weather conditions (**Rainy**, **Cloudy**, **Sunny**, **Snowy**) based on environmental features such as temperature, humidity, precipitation, wind speed, UV index, and atmospheric pressure.

## 📊 Dataset Summary
* **Total Records:** 13,200 samples
* **Target Classes:** 4 balanced classes (Rainy, Cloudy, Sunny, Snowy)
* **Features:** Temperature, Humidity, Wind Speed, Precipitation, Cloud Cover, Pressure, UV Index, Season, Visibility, Location

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
* **Algorithms:** Random Forest Classifier, XGBoost
